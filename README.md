# FoodList Support

Welcome to the support page for **FoodList**, your food planning app that helps you plan meals and manage shopping lists, alone or together. 
Willkommen auf der Support-Seite für **FoodList**, deiner Essensplan-App mit der du Mahlzeiten planen und Einkaufslisten verwalten kannst, allein oder gemeinsam mit anderen.

Thank you for using FoodList! If you are experiencing issues, have feedback, or want to suggest a feature, please use one of the methods below.

### 🐛 How to Report a Bug or Request a Feature
The easiest way to get help is to open a GitHub Issue directly in this repository:
* 👉 **[Click here to open a Support Ticket / Issue](https://github.com/thehrlein/FoodList-support/issues)**

### ✉️ Contact via Email
If you prefer not to use GitHub, you can reach out directly via email at:
